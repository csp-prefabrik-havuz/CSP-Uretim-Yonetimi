# Ürün görselleri

Bu klasör, CSP Üretim Yönetimi panelinde kullanılan ürün görselleri içindir.

- Görselleri `.jpg`, `.png` veya `.webp` olarak yükleyin.
- Dosya adını stok koduyla aynı yazın. Örnek: `ITH-AIPERS1-001.jpg`
- Panelde görsel bağlantısı alanına şu biçimde adres ekleyin:
  `https://csp-prefabrik-havuz.github.io/CSP-Uretim-Yonetimi/gorseller/DOSYA-ADI.jpg`

Bu dosyalar herkes tarafından görüntülenebilir; şifre, müşteri bilgisi veya özel belge yüklemeyin.
